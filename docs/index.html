Summary

Highlights

  • 槓桿ETF的「每日重設機制」存在路徑依賴缺陷，即使標的股票回升至原點，投資者仍可能因資金損耗而面臨虧損。

Key concepts

  • 強制平倉循環 (Forced Liquidation Loop) — 資產價格下跌觸發保證金不足，券商強制賣出持倉，進一步加劇價格下跌並引發更多平倉的惡性循環。
  • 每日重設與路徑依賴 (Daily Reset & Path Dependency) — 槓桿ETF每日調整槓桿比例，導致其長期收益取決於價格波動路徑，而非單純的終點漲跌幅。
  • 金融傳染 (Financial Contagion) — 單一市場的波動促使跨國基金調整整體資產配置或提高現金比重，將風險傳播至其他無關市場。
