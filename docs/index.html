Summary

新加坡堅持「發展型國家」模式，保留了強大的製造業（半導體佔GDP的6%），並成功透過政府引導產生「擠入效應」，使私營企業成為研發投資的主力（私營研發達89.5億新元，遠超公營）。相反，香港在製造業北移後過度依賴金融與地產，研發支出仍由政府主導（佔57%），且政策常受制於既得利益集團（如的士牌照爭議）。

Highlights

  • 新加坡2014至2024年間實質GDP年均複合增長率為3.2%，約為香港（1.1%）的三倍。

Key concepts

  • 擠入效應 (Crowding-in Effect) — 政府率先投資基礎設施或研發，降低風險以吸引私營資本跟進投資。
